# Tests

Browser and logic checks for `index.html`. They aren't part of the app.

Setup (once): `npm i playwright && npx playwright install chromium`

- `node tests/syntax.js` syntax-checks every inline script.
- `node tests/<name>.js` runs a headless Chromium check. `harness.js` serves the page locally, skips the login gate (pass `auth:false` to see it), mocks Binance REST and all WebSockets, and blocks every other network call, so no real API is used. Other options: `consent:false` (no consent seeded), `mobile` (touch phone), `reducedMotion:"reduce"`.
- Optional: put `lwc.js` (lightweight-charts 4.1.3) and `h2c.js` (html2canvas 1.4.1) in `tests/vendor/` to run fully offline.
- `legal.js`: every `#/legal/<doc>` route renders with its placeholders, the footer links work, deep links survive a reload, WebSockets stay connected and no entity text shows.
- `alertlines.js`: active alerts are drawn as lines with scale labels on all charts, and the click-to-edit (price, condition, message), drag and delete paths work; the custom message shows in the fired toast, and edits never cause duplicate fires.
- `privacy.js`: the consent banner's Reject equals Accept; no IndexedDB before consent; the consent log, cookie settings and withdraw work; export JSON; delete-all with confirmation also disconnects the feeds; the request form is gated; legal pages open over the sign-in screen.
- `mobile.js`: phone layout at 375 and 390px. Checks the tab bar and More sheet, no page overflow, 44px targets, touch pan, pinch, long-press, tapping "+", dragging an alert line, the bottom-sheet editor and touch drawing. `mshots.js WxH` takes phone screenshots.
- `signin.js`: the sign-in screen at desktop and 390px. Checks that the backdrop animates (and stays static with reduced motion), the real ticker snippets, Tab order, guest mode (nothing in localStorage or IndexedDB, survives a reload in the same tab, charts and screener work), the guest prompt for alerts and settings (focus, Tab, Esc), and signing in from guest mode with no reload or new sockets, after which saving starts. It writes `shots/11_signin.png` and `shots/m/390_signin.png`.
- `templates.js`: chart templates. Covers save with and without the symbol, load (style, indicators, panes, drawings), rename (including duplicates), the default applied on the next load, delete with confirmation, JSON export, hostile import (sanitised, no script runs), bad JSON, Esc and Tab, the guest prompt, and a 390px bottom sheet. It writes `shots/12_templates.png` and `shots/m/390_templates.png`.
- `drawpresets.js`: drawing templates and instant styles. Covers the debounced auto-save of colour, width and line type (the last-used style becomes the default), built-in templates for trend, horizontal ray, Fib and long/short (R:R moves the target), save-as, the ★ default, reload, and the guest prompt. It writes `shots/13_drawing_templates.png`.
- `claims.js`: checks that the scoring functions are byte-identical to the original baseline (`scorefns.js` has the reference hashes), there are no flagged marketing phrases in the visible UI, the not-advice notes are next to scores, the preset and timeframe help matches the code, and BUY/SELL are untouched.
- `a11y.js`: axe-core WCAG 2.1 A/AA checks on all pages in both themes and on the main dialogs, plus keyboard paths: skip link, nav, sortable headers, symbol cells, dialog focus trap, Esc and focus return, dock toggles, focus outlines and icon-button names. Install with `npm i -D axe-core`.
- `heatmap.js`: Heatmaps page. Checks exact tile values against the candles, live ticks updating tiles in place with no new sockets, a treemap with no overlaps on desktop and phone, the colour metrics, keyboard and tooltip, a first paint from the cache within one frame with candle downloads blocked, and reduced motion.
- `motion.js`: animations. Checks page transitions, tick flashes on the screener table (continued across re-renders, green up and red down) and the chart price, the heatmap tile fade-in sweep, the skeleton shimmer on loading placeholders, and dialog and phone-sheet entrances. Also checks that nothing animates under reduced motion, that render stays fast during 60 ticks, and that no sockets are added.
- `shortcuts.js`: the “?” keyboard-shortcut overlay. Checks that it opens and closes, ignores “?” while typing, over another dialog and on the sign-in screen, and that it is a labelled dialog with focus moving in and returning, axe-clean in both themes. Also checks that the current page’s section comes first, that the footer button opens it, and that every listed chart, list and heatmap shortcut does what the list says.
- `minicharts.js`: mini-chart mode. Checks the toggle, that the cards show the same symbols in the same order as the table page, exact price and change values, drawn canvases, that a live tick redraws only the changed card, the interval switch and loading state, keyboard open, persistence, axe in both themes, two columns on phone, render cost, and that no sockets are added.
- `sound.js`: the alert sound cue. Checks that it is off by default (no audio at all), on for the tab only without consent, remembered only with the “Optional preferences” consent and deleted on withdrawal, and saved once consent is given if it was turned on before. Also checks the banner’s new category (off by default, Accept/Reject), that old consent records count as no, the cookie notice, axe, and that triggered alerts are logged.
- `summary.js`: the end-of-day session summary. Checks position-tool P&L against an independent recalculation from the candles (one closed and one open seeded position), breadth and top movers against the previous daily close, that only today’s alerts are counted (including one triggered through the feed), the downloaded text, empty states, the evening chip (once a day), the phone More-sheet entry with no sideways scroll, and axe in both themes.
- `postool.js`: Long/Short Position tools on desktop and at 390px with touch. Checks click-to-place with the default R:R, exact R:R/Qty/P&L/Amount labels for long and short (open and closed), handle drags (target, stop, entry, width), remembered defaults, the settings dialog (live apply and Cancel), the right-click menu (clone, lock, hide, delete) and a touch drag. It writes `shots/pos_tool_after.png` and `shots/m/390_position*.png`.
- `logic_pos.js`: position maths (quantity from risk, leverage cap, lot size, precision, R:R) and the open/target/stop state, where the stop counts first and the entry bar is excluded.
